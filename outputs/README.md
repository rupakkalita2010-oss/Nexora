# Designora marketplace

The completed Next.js project is in the folder one level above this guide.

## Run it locally

1. Install Node.js 20 or newer from nodejs.org.
2. Open a terminal in the project folder.
3. Run `pnpm install` (or `npm install`).
4. Run `pnpm dev` (or `npm run dev`).
5. Open `http://localhost:3000` in your browser.

## Included experiences

- Premium dark marketplace home page with category and price filters
- Search, product details, wishlist, cart, mock checkout, and instant-download library
- Login, sign-up, Google/GitHub demo sign-in, buyer profile, and messages
- Seller workspace with earnings, analytics, orders, payouts, and a listing-upload draft flow
- Responsive layout for desktop, tablet, and mobile

## Before a public launch

The user interface uses safe demo data. To accept real money and users, connect a hosted database, Stripe, storage for design files, and real authentication providers using your own accounts and legal policies.
